# «Питомец Финни» (Finni Pet)

Интерактивное мобильное приложение и игровой сервис по повышению финансовой грамотности для детей и подростков. Через заботу о виртуальном питомце Финни ребёнок учится распределять карманные деньги по правилу бюджетирования (50/30/20), копить на долгосрочные цели, совершать осознанные покупки в магазине и проходить обучающие квесты. Для родителей предусмотрен защищённый раздел со статистикой и управлением игровыми периодами.

## 📁 Структура проекта

Репозиторий организован в виде монорепозитория, объединяющего серверную и клиентскую части:

```text
Finni/
├── backend/               # Серверная часть (FastAPI, PostgreSQL, Alembic, Docker)
│   ├── app/               # Исходный код API (роутеры, модели, логика экономики)
│   ├── content/           # Каталог товаров, заданий и игровых целей (catalog.json)
│   ├── deploy/            # Конфигурации для развёртывания (Nginx)
│   ├── migrations/        # Миграции базы данных Alembic
│   ├── scripts/           # Скрипты экспорта OpenAPI, smoke-тестов и т.д.
│   ├── tests/             # Модульные и интеграционные тесты (pytest)
│   ├── compose.yaml       # Docker Compose файл (PostgreSQL, Migrate, API, Nginx)
│   ├── Dockerfile         # Сборка контейнера бэкенда
│   └── pyproject.toml     # Зависимости Python и конфигурация проекта
│
├── mobile/                # Мобильное приложение (React Native / Expo, TypeScript)
│   ├── src/
│   │   ├── components/    # Переиспользуемые UI-компоненты (TabBar, карточки и т.д.)
│   │   ├── constants/     # Темы оформления, списки квестов и товаров
│   │   ├── navigation/    # Навигация (React Navigation: Stack & Bottom Tabs)
│   │   ├── screens/       # Экраны (Dashboard, Budget, Shop, Quests, Parent, Onboarding)
│   │   ├── store/         # Управление состоянием (Zustand + AsyncStorage)
│   │   ├── types/         # TypeScript-типизация моделей и навигации
│   │   └── utils/         # Вспомогательные функции
│   ├── App.tsx            # Корневой компонент приложения
│   ├── app.json           # Конфигурация Expo
│   └── package.json       # Скрипты и зависимости Node.js
│
├── .github/workflows/     # CI/CD автоматизация (GitHub Actions)
└── README.md              # Данный файл с описанием и инструкциями
```

## 🛠️ Предварительные требования

Перед началом работы убедитесь, что в вашей системе установлены:

- **Git**
- **Docker и Docker Compose** (рекомендуется для быстрого запуска бэкенда)
- **Python 3.12+** (если планируется локальный запуск бэкенда без Docker)

- Приложение **Expo Go** на смартфоне (iOS / Android) или настроенный эмулятор Android Studio для мобильной разработки

## 🚀 Быстрый запуск

### 1. Запуск бэкенда через Docker Compose (Рекомендуемый способ)

Бэкенд поднимается в связке с базой данных PostgreSQL, автоматическим накатом миграций, импортом каталога и обратным прокси Nginx.

1. Перейдите в каталог `backend`:
   ```bash
   cd backend
   ```

2. Создайте файл конфигурации окружения `.env` из примера:
   - **Linux / macOS**:
     ```bash
     cp .env.example .env
     ```
   - **Windows (PowerShell)**:
     ```powershell
     Copy-Item .env.example .env
     ```

3. Откройте `.env` и задайте безопасный пароль для базы данных:
   ```env
   POSTGRES_PASSWORD=my_secure_password_123
   HTTP_PORT=8080
   ```

4. Запустите сервисы:
   ```bash
   docker compose up --build -d
   ```

5. Проверьте работоспособность:
   - **Интерактивная документация Swagger UI**: [http://localhost:8080/docs](http://localhost:8080/docs)
   - **Спецификация OpenAPI**: [http://localhost:8080/openapi.json](http://localhost:8080/openapi.json)
   - **Healthcheck эндпоинт**: [http://localhost:8080/health/ready](http://localhost:8080/health/ready)

6. Остановка контейнеров:
   ```bash
   docker compose down          # Без удаления данных
   docker compose down -v       # С очисткой тома базы данных
   ```

---

### 2. Запуск мобильного приложения (React Native / Expo)

1. Откройте новый терминал и перейдите в каталог `mobile`:
   ```bash
   cd mobile
   ```

2. Установите зависимости проекта:
   ```bash
   npm install
   ```

3. Запустите сервер разработки Expo:
   ```bash
   npm start
   ```
   или с явным указанием платформы:
   - В браузере (быстрый предпросмотр):
     ```bash
     npm run web
     ```
   - На Android-эмуляторе:
     ```bash
     npm run android
     ```
   - На iOS-симуляторе (только macOS):
     ```bash
     npm run ios
     ```

4. **Запуск на физическом устройстве**:
   - Отсканируйте QR-код из терминала или из открывшейся веб-страницы Metro Bundler через приложение **Expo Go** (Android) или камеру (iOS).
   - Убедитесь, что мобильное устройство и компьютер подключены к одной локальной Wi-Fi сети.

## 💻 Локальная разработка бэкенда (без Docker)

Если вы разрабатываете API и хотите запускать сервер напрямую с hot-reload:

### Windows (PowerShell):

```powershell
cd backend

# Создание и активация виртуального окружения
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Установка зависимостей с тестовыми пакетами
python -m pip install --upgrade pip
python -m pip install -e ".[test]"

# Инициализация базы данных (по умолчанию SQLite, если не задан DATABASE_URL)
alembic upgrade head

# Импорт игрового каталога (товары, цели, задания)
python -m app.content content/catalog.json

# Запуск сервера разработки FastAPI
uvicorn app.main:app --reload --port 8000
```

> **Примечание:** Если хотите подключить локальный PostgreSQL, задайте перед миграциями:
> ```powershell
> $env:DATABASE_URL = "postgresql+psycopg://finni:password@localhost:5432/finni"
> ```

### Linux / macOS (Bash):

```bash
cd backend

# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install --upgrade pip
pip install -e ".[test]"

# Применение миграций и загрузка контента
alembic upgrade head
python -m app.content content/catalog.json

# Запуск Uvicorn
uvicorn app.main:app --reload --port 8000
```

При запуске без Nginx API будет доступно по адресу [http://localhost:8000/docs](http://localhost:8000/docs).

## 🧪 Тестирование и валидация

### Тесты бэкенда

```bash
cd backend

# Быстрый запуск модульных и интеграционных тестов (SQLite в памяти)
pytest -q

# Проверка синхронизации схемы БД и миграций
alembic check

# Проверка актуальности схемы openapi.json
python scripts/export_openapi.py
```

Для запуска тестов в изолированном PostgreSQL внутри Docker:
```bash
docker compose exec db createdb -U finni finni_test
docker compose -f compose.yaml -f compose.test.yaml run --build --rm tests
```

### Проверка типов мобильного приложения

```bash
cd mobile
npm run tsc
```

## 🎮 Ключевые возможности приложения

- 🐾 **Питомец Финни**: интерактивный аватар с кастомизацией внешности (цвет, порода, аксессуары), уровнями сытости и настроения.
- 📊 **Бюджетирование (50/30/20)**: распределение дохода периода на обязательные траты (Нужды), развлечения (Желания) и накопления (Копилка).
- 🎯 **Копилка и Цели**: выбор финансовой цели, отслеживание прогресса, прогноз достижения при текущем темпе сбережений.
- 🛍️ **Магазин**: покупка еды и предметов для питомца с учетом планового бюджета.
- 💡 **Квесты**: интерактивные обучающие викторины с моментальной обратной связью и монетами за правильные ответы.
- 👨‍👩‍👧 **Родительский контроль**: доступ через арифметический барьер к экрану с аналитикой дисциплины трат, регулярности накоплений и кнопкой безопасного сброса прогресса.
- 🔄 **Идемпотентный Sync API**: сервер поддерживает офлайн-очередь команд с гарантией целостности состояния и защитой от рассинхронизации ревизий (`POST /api/v1/sync`).
