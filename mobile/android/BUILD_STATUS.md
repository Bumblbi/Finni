# Состояние release APK — 24.09.2026

Подписанный APK пока не создан. Проверка показала, что Gradle проходит конфигурацию Expo и React Native, устанавливает SDK 36, NDK 27.1 и CMake 3.22.1, генерирует файлы приложения и начинает нативную сборку. Самая дальняя попытка остановилась на `:app:configureCMakeRelWithDebInfo[arm64-v8a]`: Ninja завершился с `Access violation` при создании тестового проекта компилятора. Последующая попытка прервалась раньше из-за повреждённого запуска Gradle, который принял путь к `gradlew.bat` за имя задачи.

На этой машине также зарегистрированы аварийные завершения `node.exe` 22.19.0, `cmd.exe` и `java.exe` с кодом `0xC0000005`. Они возникали на разных задачах Gradle, а не на одной строке приложения. Новый Node 22.23.3 проверен по официальной SHA-256, JDK 17 проверен по версии. Оба находятся в `mobile/.artifacts` и не заменяют системные установки. Копия Android SDK там же позволяет запустить Clang без ошибки доступа, но не устранила аварии Ninja. Логи попыток находятся в `mobile/.artifacts/build-logs`. Следующий практический шаг — перезагрузить Windows и запустить скрипт сборки в обычном локальном терминале.

Что уже исправлено в проекте:

- `settings.gradle` и `app/build.gradle` используют существующие пути зависимостей вместо вызовов Node для определения путей на этапе настройки.
- Gradle ограничен одним worker и 1 ГБ heap для уменьшения нагрузки при локальной сборке.
- `scripts/build-release.ps1` проверяет инструменты и release-ключ, запускает сборку и затем проверяет подпись и SHA-256 APK.

После стабилизации Windows запустить из `mobile`:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\build-release.ps1
```

Для быстрой проверки APK только для 64-битных Android-устройств можно указать `-Architectures arm64-v8a`. Полная release-сборка по умолчанию включает четыре ABI.

После успешной сборки проверить установку `app-release.apk` на реальном Android через ADB, пройти пять периодов, холодный запуск, родительский раздел и сброс. При последней проверке `adb devices` не показал подключённых устройств. Скриншоты, демонстрационное видео и остальные внешние материалы в рамках этой задачи не проверялись.
